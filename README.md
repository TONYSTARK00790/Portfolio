# Selvaragavan S — Portfolio

A responsive dark-themed portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Customize
- Edit text and links in `index.html`.
- Change colors and layout in `style.css`.
- Update interactions in `script.js`.
- Replace `resume.pdf` with your latest resume PDF (keep the same filename).

## Publish
Upload the extracted folder to GitHub Pages, Netlify, or Vercel as a static site.

Note: Project descriptions and skills are based on the supplied resume. Add verified project links, screenshots, and technical details before publishing.
